# quiz-me

목적은 내가 만든 결과물을 **내 말로** 설명할 수 있는지 점검하는 것이다. AI가 답을 대신 쓰지 않는다.

## 1. 질문 만들기

`docs/prd/`, `docs/adr/`, `docs/GRILL.md`, `git log`, 코드를 읽고 질문 6개를 만든다. 아래 유형을 섞는다.

1. **왜**: 이 구조·패턴·임계값을 왜 골랐나 (ADR의 "고려한 다른 길"과 비교)
2. **어디서**: 요구사항 F-nn#ACn이 코드 어디서 충족되나
3. **언제 깨지나**: 어떤 입력이나 상황에서 실패하나
4. **장애 대응**: 실패하면 어떻게 알아채고 무엇부터 확인하나
5. **안 만든 것**: 범위 밖으로 둔 것과 그 이유
6. **AI 활용**: AI에게 무엇을 맡기고 무엇을 직접 판단했나, AI 결과를 어떻게 검증했나

## 2. 하나씩 묻기

- 질문을 **하나씩** 묻고 내 답을 기다린다.
- 내 답을 아래 3단계로 채점한다. 빠진 단계만 짧게 짚는다.
  1. 구체적인 대상을 지목했나 (파일·함수·ADR 번호 수준)
  2. 그게 왜 중요한지, 무엇에 영향을 주는지 설명했나
  3. 다음에 무엇을 검증하거나 개선할지 말했나
- 내 설명과 실제 코드·ADR이 다르면 그 차이를 알려 준다. **어느 쪽이 맞는지는 내가 정한다.**

## 3. 서술형 연습 (요청할 때만)

내가 "서술형"이라고 하면 질문 하나를 골라 아래 순서로 진행한다.

1. 내가 먼저 답을 쓴다.
2. 결론 먼저 → 근거(ADR·AC·테스트 수치) → 한계와 다음 단계 순서인지 본다.
3. 고칠 문장 2개까지만 짚는다. 고쳐 쓴 전체 답안을 대신 써 주지 않는다.

## 4. 마무리

- 내가 막힌 질문만 목록으로 정리한다.
- 코드와 문서는 고치지 않는다. 설명과 코드가 다른 곳은 "확인 필요"로 목록에 남긴다.
