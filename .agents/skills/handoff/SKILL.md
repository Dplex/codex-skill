# handoff

다음 세션이 알아야 할 것만 적는다. 일어난 일을 다 적지 않는다. 결정의 이유는 ADR에 있으므로 번호만 가리킨다.

1. `git status --short`와 `git log --oneline -10`으로 상태를 확인한다.
2. `docs/HANDOFF.md`를 아래 형식으로 덮어쓴다. 각 항목은 3줄 이내다.

```markdown
# HANDOFF (<시각>)

## 목표
<무엇을 누구를 위해 만드는지 1~2문장. docs/prd/README.md 기준>

## 지금 상태
- 완료: <F번호·AC와 커밋>
- 진행 중:
- 막힌 것:

## 핵심 결정
<다음 작업에 영향을 주는 ADR 번호와 제목 한 줄씩. 제안 상태인 ADR은 따로 표시>

## 해 봤는데 안 된 것
<다음 세션이 반복하지 않게. 무엇을 했고 결과가 어땠는지>

## 먼저 읽을 파일
- docs/prd/README.md
- <이번 작업의 핵심 파일>

## 다음 할 일
1. <가장 먼저 할 것>
```

3. `[docs] handoff 갱신`으로 커밋한다.
4. 새 세션의 첫 문장을 알려 준다: `docs/HANDOFF.md를 읽고 "다음 할 일" 1번부터 이어서 해.`
